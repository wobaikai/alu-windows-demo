# 今天这一天的学习路线（照着做就行）

这个文件夹里是一个能直接打开的铝合金门窗网站示例，全部内容都可以改。

## 第 1 步：先看效果（5 分钟）

双击打开 `index.html`，浏览器里会出现一个完整网页。手机上可以缩窄窗口或真机打开试试。

## 第 2 步：自己动手改一句话（15 分钟）

用记事本或 VS Code 打开 `index.html`，找到“家安铝合金门窗”这几个字，改成你家的真实店名，保存后刷新浏览器。

你会发现：**网页上的文字不在网页里，而在一个叫 HTML 的文件里。** 这就是网页的“内容层”。

## 第 3 步：改一个颜色（10 分钟）

打开 `style.css`，最上面有一行：

```css
--primary: #0f4c81; /* 主色 */
```

把 `#0f4c81` 改成 `#b91c1c`，保存刷新。网页主色从蓝色变成了红色。

这就是网页的“外观层”，改起来非常快。

## 第 4 步：理解三个文件各管什么（10 分钟）

- `index.html`：管“有什么”——文字、板块、图片。
- `style.css`：管“长什么样”——颜色、大小、间距。
- `script.js`：管“会动什么”——菜单展开、年份更新。

以后所有网页，甚至你看到的几乎所有网站，本质都是这个结构。

## 第 5 步：把它变成你家的真实网站

需要问家里人的信息，先记下来，之后让 AI 帮你替换：

- 店名 / 老板怎么称呼
- 电话（号码在 index.html 里出现 3 次，搜 13800000000 就能找到）
- 地址、营业时间
- 真实安装照片（拍 4 张左右，用来替换案例区的占位图）
- 想突出什么服务（比如主做断桥铝，就把那个卡片放第一位）

## 以后没有大块时间怎么办

每天 15 分钟就够。给自己定规则：

1. 今天只改一个小地方（比如一个标题、一张图）。
2. 改完必须打开浏览器看效果。
3. 不会改就问 AI，把这句话复制过去：

> 我是一个零基础新手。帮我修改 `index.html` 里的店名，从“家安铝合金门窗”改成“XXX”，并告诉我改的是哪一行、为什么。

## 重要提醒

这个网站现在还是“示例”。它最重要的作用是让你用一天时间亲身感受：**做网站是不是你愿意继续学的事。**

如果今天做完你觉得有意思，哪怕只懂了一点，说明这条路值得走；如果觉得完全没感觉，那也省下了你盲目投入几个月的时间。两种结果都是收获。
